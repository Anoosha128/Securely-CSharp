# 🔐 Securely - C# Authentication System
A desktop-based authentication and password management project developed using **C# Windows Forms in Visual Studio**.

The project includes Login, Sign Up, Password Generator, Password Strength Progress Bar, Forgot Password, Delete, Welcome, and Start Page forms.

## ✨ Features:
- 🔑 Login Page
- 📝 Sign Up Page
- 🔐 Password Generator
- 📊 Password Strength Progress Bar
- 🔄 Forgot Password
- 🗑️ Delete Functionality
- 💾 Saved Form
- 👋 Welcome Page
- 🚀 Start Page
- ⏳ Loading Screen
- 🎨 Windows Forms GUI

## 🛠️ Technologies Used:
- C#
- Windows Forms
- Visual Studio
- .NET Framework

## 📋 Project Forms:
The project contains multiple Windows Forms for different functionalities:

- `Form1.cs` - Main form
- `Sig-up page.cs` - Sign Up functionality
- `PasswordGenerator.cs` - Password generation
- `progressbar.cs` - Password strength progress
- `Forget Password.cs` - Password recovery
- `Delete.cs` - Delete functionality
- `saved form.cs` - Saved information form
- `startpage.cs` - Start page
- `Welcomepg.cs` - Welcome page
- `loading.cs` - Loading screen

## 🚀 How to Run:
1. Clone or download this repository.
2. Open the project in **Visual Studio**.
3. Open the `.sln` solution file.
4. Build the project using:

```text
Build → Build Solution
```

5. Press **F5** or click **Start** to run the application.
